# 🔗 simple-bio-link

A super simple, modern, and highly customizable link-in-bio page contained entirely within a **single HTML file**. No complex setups, no build tools, no frameworks—just edit the config and you're ready to host anywhere.

## ✨ Features

- **Single File Deployment:** Everything (HTML, CSS, JS) is in one file. Host it instantly on GitHub Pages, Vercel, Netlify, or your own server.
- **Dead Simple Config:** Customizing your page takes 30 seconds. Just edit the `CONFIG` object at the top of the file.
- **Dynamic Icons:** Automatically fetches perfect, high-quality icons for all major social and crypto platforms via SimpleIcons.
- **Discord-Style Badges:** Show off an "Online/Idle/DND" status indicator and a clean verified checkmark next to your username.
- **Built-in Music Player:** Play your favorite tracks in the background with a beautiful "simple" or "advanced" audio player.
- **Crypto & Payments:** Special `copy:` links allow visitors to click and instantly copy your crypto addresses (Bitcoin, Ethereum, CashApp, etc.) to their clipboard.
- **Rich Embeds (Open Graph):** Automatically generates beautiful link previews when you share your URL on Discord, Twitter, or iMessage.
- **Eye Candy:** Includes optional 3D mouse tilt effects, custom cursors, staggered fade-in animations, and typing effects.

## 🚀 Getting Started

1. **Fork or Download** this repository.
2. Open `index.html`
3. Scroll down to the `CONFIG` object and change the values to your own!
4. **Host it!** Drag and drop the file into a free host like [Netlify Drop](https://app.netlify.com/drop) or publish it via GitHub Pages.
